# MVP Scope

Purpose

Deliver a production-ready platform capable of managing the Youth Conference.

---

Included

✔ Admin Authentication

✔ Event Management

✔ Public Registration

✔ People Database

✔ Team Assignment

✔ QR Code Generation

✔ QR Check-in

✔ Attendance

✔ Games

✔ Leaderboard

✔ Confirmation Email

---

Excluded

✘ Member Login

✘ Departments

✘ Giving

✘ Prayer Requests

✘ Sermons

✘ Notifications

✘ Mobile App

✘ Weekly Attendance

✘ Visitor Follow-up

✘ Analytics

These features belong to later phases.

---

Success Criteria

An administrator can:

Create an event.

Publish registration.

View registrations.

Assign teams.

Generate QR codes.

Check attendees in.

Record game scores.

Determine winning team.

Export participant data.

Every participant becomes a Person in the database.
